# bitneedle

Convenience crate for Bitneedle public decoder and interoperability APIs.

This crate is published so Bitneedle records can be independently inspected,
verified, played back, and preserved. It is not a commercial Bitneedle record
authoring platform and does not grant rights to create, mint, issue, sell, or
market Bitneedle records outside the Apache-2.0 license as applied to this
crate.
